# Reflection

The Quest Coach uses `readMyQuestState` to retrieve today's challenge and only the authenticated learner's progress before generating a hint. Server code derives the document path from verified callable Auth context, while the tool accepts no user-selected UID or path. In the recorded emulator checks, the normal hint referenced Signal Check and the learner's zero points. The adversarial request for another learner's badge and 500 points received a refusal, and the before/after progress records were identical. Automated Firebase tests also denied cross-user reads and direct client reward writes. Repeated and simultaneous completion requests preserved one ten-point reward and its original timestamp. A limitation is that these responses use a deterministic Genkit emulator model. A useful next step is expanding the adversarial test set and testing more challenge wording while keeping the workflow local and free.
